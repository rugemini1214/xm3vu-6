為個人與小團體自由行設計的 PWA (漸進式網頁應用程式) 小工具
完全運行於您的手機瀏覽器中，無需網路即可查看行程與記帳

目前版本：v01.13

✨ 核心功能
1. 行程管理
2. 記帳與分帳
3. 實用日語
4. PWA 離線技術
5. 資料匯出

🛠️ 技術說明
架構：純前端開發 (HTML5 / CSS3 / Vanilla JavaScript)
儲存：使用瀏覽器 localStorage，資料完全存於您的手機中
隱私：無後端資料庫，不追蹤、不上傳任何個人數據至伺服器

🚀 如何安裝與使用
在手機瀏覽器 (Safari/Chrome) 開啟該網址
iOS (Safari)：點擊分享按鈕 ->「加入主畫面」
Android (Chrome)：點擊選單 ->「安裝應用程式」或「加到主畫面」

⚠️ 注意事項
由於資料僅儲存於瀏覽器快取，清除瀏覽器資料 (Clear Cache/Data) 會導致行程與記帳消失
建議定期使用「匯出報表」功能備份重要資料

此專案代碼由 Google Gemini 生成與優化
